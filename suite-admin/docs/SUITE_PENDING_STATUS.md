## Completed locally since the operations handoff

- Central delivery now pins target instance UUID and production/staging environment. Missing or invalid deployment configuration is not counted as a configured adapter and is not scheduled.
- Ready jobs are refreshed after three minutes, before a product mirror's five-minute freshness deadline. Refresh preserves job/version, trial dates, grants and binding readiness. Leases still prevent overlapping or stale acknowledgements.
- Product servers can resolve central access from an authoritative local tenant ID using their existing product-scoped machine credential. Unenrolled accounts return `managed:false, allowed:false`; the calling server must explicitly choose whether to retain legacy unenrolled users during rollout.
- The shared adapter contract validates product, organisation, verified member identities, member capacity, access dates and snapshot freshness. It rejects duplicate identities, stale snapshots, deployment mismatches and invalid credentials. **This is shared infrastructure, not four working provisioning adapters.** No product storage/provisioning implementations are plugged into it yet.
- The modern WhatsApp backend HR bot has a Workforce access check before processing an inbound message, before each tool, and before sending a normal reply or welcome message. Access denials do not send a fallback message. A second check stops a reply if access is revoked while AI processing runs. Tool user/organisation must equal the registered HR account; AI input cannot override that scope. No shared phone session is disconnected.
- These four HR runtime files were installed locally using `suite-integrations/runtime-manifest.json`. The generated package has its own staging directory and does not overwrite earlier connector snapshots. The server runtime settings are in `suite-integrations/env/runtime-access.env.example`. `SUITE_ACCESS_ENABLED` must be set to `true` on release for the checks to run. An unset flag retains existing HR behaviour and must never count as suite enforcement.
